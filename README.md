# دفتر التجار - تطبيق إدارة مستندات الذهب 📒💎

تطبيق ويب جاهز للتحويل لـ APK يعمل على أجهزة الأندرويد.

---

## 📱 الطريقة الأسهل: تحويل التطبيق إلى APK في 3 خطوات

### 🟢 الخطوة 1: نشر التطبيق أونلاين (مجاني — بدون حساب)

1. ادخل على هذا الموقع: **https://app.netlify.com/drop**
2. **اسحب مجلد `dist` بالكامل** وأفلته داخل الصندوق المنقط في الموقع
3. انتظر ثوانٍ معدودة، هتحصل على رابط زي:
   `https://random-name-123.netlify.app`
4. **انسخ الرابط ده** — هتحتاجه في الخطوة الجاية

> ⚠️ ملحوظة: الرابط ده مجاني وهيفضل شغال للأبد. لو عايز تغير الاسم، اعمل حساب مجاني على Netlify.

---

### 🟢 الخطوة 2: تحويل الرابط إلى ملف APK

1. ادخل على: **https://www.pwabuilder.com**
2. الصق الرابط اللي حصلت عليه من الخطوة السابقة في الخانة الكبيرة
3. اضغط **Start**
4. هيفحص التطبيق ويديك تقييم. اضغط **Package For Stores** (أعلى الصفحة)
5. اختار **Android**
6. اضغط **Generate Package**
7. هيتحمل عندك ملف ZIP فيه:
   - `app-release-signed.apk` ← **ده اللي محتاجه**
   - تعليمات إضافية

---

### 🟢 الخطوة 3: تثبيت التطبيق على الموبايل

1. ابعت ملف `app-release-signed.apk` لموبايلك (واتساب، إيميل، Google Drive، أو كابل USB)
2. على الموبايل، افتح الملف
3. لو ظهرت رسالة "تثبيت من مصادر غير معروفة"، فعّل الإذن من الإعدادات
4. اضغط **تثبيت**
5. ✅ خلاص! التطبيق ظهر في قائمة تطبيقاتك زي أي تطبيق عادي

## 🎯 المميزات

- ✅ **يعمل بدون إنترنت** بعد فتحه أول مرة
- ✅ **البيانات محفوظة على الجهاز** (لا تضيع لما تقفل التطبيق)
- ✅ **كاميرا حقيقية** للتصوير المباشر
- ✅ **تخزين كبير** يكفي لآلاف المستندات (IndexedDB)
- ✅ **واجهة عربية** كاملة ومناسبة للموبايل

## 🛠 طريقة بديلة: تعديل الكود وإعادة البناء

لو عايز تعدل في الكود (تغير الألوان، تضيف ميزة، إلخ):

### المتطلبات:
- **Node.js** نسخة 18 أو أحدث ([حمّله من هنا](https://nodejs.org))

### الأوامر:
```bash
# الدخول لمجلد المشروع
cd gold-app

# تثبيت المكتبات (مرة واحدة فقط)
npm install

# تشغيل وضع التطوير (للاختبار)
npm run dev

# بناء النسخة النهائية (تطلع في مجلد dist)
npm run build
```

بعد التعديل والبناء، أعد رفع مجلد `dist` على Netlify ثم استخدم PWABuilder تاني.

## ❓ أسئلة شائعة

**س: هل البيانات بتتحفظ على الإنترنت؟**
ج: لا، البيانات كلها (التجار + الصور) بتتحفظ على ذاكرة موبايلك بس. مفيش سيرفر.

**س: لو غيرت الموبايل، البيانات هتروح؟**
ج: أيوه، لأنها محفوظة على الجهاز. لو عايز نسخة احتياطية أو مزامنة بين أجهزة، قولي وأضيفها.

**س: APK من PWABuilder آمن؟**
ج: أيوه، PWABuilder مشروع رسمي من Microsoft ومفتوح المصدر.

**س: هل ممكن أعمل التطبيق ده على iPhone؟**
ج: نفس خطوة Netlify، وبعدين تفتح الرابط على Safari وتضيفه للشاشة الرئيسية ("Add to Home Screen"). على iPhone مفيش APK، بس هيشتغل زي تطبيق عادي.

**س: ممكن أضيف لوجو الشركة بتاعتي؟**
ج: استبدل الملفين `public/icon-192.png` و `public/icon-512.png` بصورتك (بنفس المقاسات)، ثم أعد البناء.

## 🆘 لو حصلت مشكلة

- **Netlify Drop مش شغال:** جرب **Vercel** أو **Cloudflare Pages** (بيعملوا نفس الحاجة)
- **PWABuilder بيقول التطبيق ناقص حاجة:** المفروض شغال تمام، بس لو حصل مشكلة قولي وهظبطها
- **الكاميرا مش بتفتح في APK:** الموبايل لازم يدي إذن للكاميرا أول مرة. لو رفضت الإذن، روح إعدادات التطبيق في الموبايل وفعّله
